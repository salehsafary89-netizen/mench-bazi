# سامانه صابر بسیج

سامانه جامع مدیریت پایگاه

## ویژگی‌ها

- 📱 **PWA قابل نصب** - نصب آسان بر روی اندروید، iOS و دسکتاپ
- 🔒 **HTTPS و امن** - رمزگذاری کامل اطلاعات
- ⚡ **کارایی بالا** - بارگذاری سریع
- 🌐 **حالت آفلاین** - کار بدون اتصال اینترنت
- 🎨 **طراحی RTL** - پشتیبانی کامل فارسی و راست‌به‌چپ
- 💾 **ذخیره‌سازی محلی** - حفظ داده‌های کاربر

## نحوه نصب

### از طریق GitHub Pages
1. سایت به صورت خودکار در آدرس زیر منتشر می‌شود:
   ```
   https://salehsafary89-netizen.github.io/mench-bazi/
   ```

2. صفحه را باز کنید و بر روی دکمه "نصب بر روی صفحه خانگی" کلیک کنید

### برای توسعه‌دهندگان
```bash
# کلون کردن Repository
git clone https://github.com/salehsafary89-netizen/mench-bazi.git
cd mench-bazi

# اجرای سرور محلی (اختیاری)
python -m http.server 8000
# یا
npx http-server
```

سپس به `http://localhost:8000` بروید.

## فایل‌های پروژه

- `index.html` - صفحه اصلی
- `manifest.json` - تنظیمات PWA
- `sw.js` - Service Worker برای آفلاین
- `.nojekyll` - غیرفعال کردن Jekyll
