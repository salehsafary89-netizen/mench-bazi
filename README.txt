سامانه صابر بسیج — بسته آماده GitHub Pages

فایل‌های لازم در ریشه Repository:
- index.html
- manifest.json
- sw.js
- saber-app-icon.png
- .nojekyll

روش انتشار:
1) همه فایل‌های این پوشه را در ریشه Repository قرار دهید.
2) GitHub > Settings > Pages
3) Source = Deploy from a branch
4) Branch = main و Folder = / (root)
5) Save
6) آدرس: https://USERNAME.github.io/REPOSITORY/

برای نصب واقعی PWA و Service Worker باید سایت روی HTTPS یا localhost باز شود.
ذخیره اطلاعات داخل برنامه محلی است و تاریخ انقضا ندارد؛ پاک‌کردن داده‌های مرورگر یا حالت ناشناس می‌تواند داده محلی را حذف کند.
