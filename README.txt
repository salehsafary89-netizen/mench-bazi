سامانه صابر بسیج — نسخه آماده GitHub Pages / HTTPS

فایل اصلی: index.html
Manifest: manifest.json
Service Worker: sw.js

برای انتشار رایگان:
1) این پوشه را در یک Repository گیت‌هاب قرار دهید.
2) Settings > Pages را باز کنید.
3) Source را روی Deploy from a branch بگذارید.
4) Branch = main و Folder = / (root) را انتخاب کنید.
5) Save را بزنید.
6) آدرس https://USERNAME.github.io/REPOSITORY/ را باز کنید.
7) در Settings > Pages گزینه Enforce HTTPS را فعال کنید.

پس از HTTPS، Chrome می‌تواند سامانه را به‌صورت PWA نصب کند.
