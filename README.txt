سامانه صابر بسیج — نسخه تمیز HTTPS / PWA

فایل‌های اصلی:
- index.html
- manifest.json
- sw.js
- saber-app-icon.png
- .nojekyll

قرار دادن در GitHub:
1) همه فایل‌ها را در ریشه Repository قرار بده.
2) Settings > Pages
3) Source = Deploy from a branch
4) Branch = main و Folder = /(root)
5) Save

بعد از انتشار:
https://USERNAME.github.io/REPOSITORY/
